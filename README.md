# Exercícios Práticos de Econometria (Econometric Analysis, Greene)

Este repositório armazena a minha coleção de exercícios práticos implementados durante o curso de mestrado em Economia (PPGE-UFF), utilizando majoritariamente as atividades propostas no livro **Econometric Analysis (William Greene)**.

## Estrutura do Repositório

| Pasta / Tópico | Principais Ferramentas / Modelos |
| :--- | :--- |
| **`lista01_PNADc/`** | Estatísticas Descritivas a partir da PNADc |
| **`lista02_cap03_greene/`** | Regressão múltipla e álgebra de matricial (Greene / Koop & Tobias) |
| **`lista03_cap05_greene/`** | Estimação com matrizes particionadas e manipulação de dados em painel (Greene / Koop & Tobias) |
| **`lista03_cap08_greene/`** | Variáveis instrumentais e mínimos quadrados em dois estágios |

## Tecnologias Utilizadas
* **Linguagem:** R / RMarkdown (`.Rmd`)
* **Principais Pacotes:** `tidyverse`, `estimatr`, `rdrobust`, `sandwich`, `modelsummary`
